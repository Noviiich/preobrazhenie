# Преображение

Готовый адаптивный frontend парикмахерской в Плещеево. Vite, семантический HTML, CSS и JavaScript без клиентского фреймворка. Сервер приложения, база данных и ключи API не нужны.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm ci
npm run dev
```

Локальный адрес: `http://localhost:5173`.

```bash
npm run build
npm run preview
```

Готовый сайт находится в `dist/`. Эту папку можно разместить на любом статическом хостинге. Для размещения в подкаталоге задайте `VITE_BASE_PATH=/имя-папки/`. Пути к изображениям, шрифтам и favicon адаптируются автоматически. Переменная `SITE_URL` задаёт абсолютный адрес для canonical, Open Graph и JSON-LD.

## Что работает

- Адаптивная вёрстка и мобильное меню; закреплённая кнопка записи появляется после прокрутки первого экрана.
- Категории услуг, ориентировочная стоимость и продолжительность.
- Запись с выбранной услугой или понравившимся образом, редактируемый текст сообщения.
- SMS на `+79102664823`, с учётом формата ссылки iPhone/iPad и Android.
- Сообщения сообщества: `https://vk.me/club242078993`; страница: `https://vk.ru/club242078993`.
- Явное копирование текста для VK. Сайт не отправляет сообщения сам и не подтверждает запись: время согласуется в переписке.
- Звонок, ссылка на поиск адреса в Яндекс Картах, раскрывающиеся ответы на вопросы.
- Управление с клавиатуры, нативные модальные окна с возвратом фокуса, поддержка reduced motion.
- Локальные шрифты с кириллицей, адаптивные WebP и отложенная загрузка второстепенных фотографий.

## Контент и редактирование

- `src/data.js` — услуги, примерные цены, продолжительность и контактная конфигурация. Статические контактные ссылки и SEO-описание также находятся в `index.html`.
- `index.html` — тексты, разделы, контакты и SEO-метаданные.
- `src/styles.css` — дизайн, адаптивность и состояния элементов.
- `src/main.js` — интерактивность; без аналитики, cookies и отправки данных в backend.
- `public/images/` — изображения в WebP. Это сгенерированные редакционные иллюстрации для вдохновения, а не фотографии клиентов или интерьера салона.
- `docs/image-prompts.json` — исходные промпты; использован встроенный imagegen, без API/CLI.
- `public/fonts/` — Cormorant Garamond и Manrope, лицензии SIL OFL приложены.

Цены и длительность даны как ориентир и требуют сверки с реальным прайсом салона. Рабочие часы и реальные отзывы не выдуманы: время приёма предлагается уточнить при записи. Для записи через VK у сообщества должны быть открыты сообщения.

## Проверки

```bash
npx playwright install chromium
npm test
```

Playwright проверяет сценарии выбора услуги и образа, SMS, копирование текста, мобильное меню, FAQ, отсутствие горизонтального переполнения при ширине 320/390/768/1440 px, загрузку ресурсов, возврат фокуса и автоматические правила WCAG AA через axe-core. Эти проверки не отправляют SMS и сообщения VK.

## Дизайн

Молочный фон, шоколадные и терракотовые акценты, выразительная антиква и спокойная журнальная композиция. Фотографии служат референсами образа. Данные записи не сохраняются между посещениями и не передаются автоматически.

## GitHub Pages

Workflow `.github/workflows/pages.yml` собирает и публикует сайт при каждом push в `main`; его также можно запустить вручную во вкладке Actions.

В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow сам получает адрес сайта и базовый путь от GitHub Pages, поэтому поддерживает как проектный адрес `https://username.github.io/repository/`, так и собственный домен. Для домена дополнительно настройте Custom domain в Pages и DNS.

Пример локальной сборки для проектного адреса:

```bash
VITE_BASE_PATH=/preobrazhenie/ SITE_URL=https://noviiich.github.io/preobrazhenie/ npm run build
```

Проверка production-сборки в подкаталоге:

```bash
npm run test:pages
```

Тест проверяет загрузку всех изображений и шрифтов, SEO-адрес и изображение модального окна, которое создаётся через JavaScript. Проверка выполняется на desktop и mobile; публикации не происходит.

Workflow соответствует [официальной инструкции Vite для GitHub Pages](https://vite.dev/guide/static-deploy.html#github-pages).
